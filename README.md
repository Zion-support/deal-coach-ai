## What it does

Deal Coach AI reads each opportunity's emails, calls and CRM fields to recommend the next best action, surface qualification gaps (MEDDICC/BANT) and draft responses to objections — inside the rep's workflow.

## Key features

- **Next-best-action** — ranked actions per deal with rationale.
- **Qualification gaps** — missing champion, metrics, decision process flagged.
- **Objection responses** — drafted from your win library.
- **Call-prep briefs** — stakeholder map + talk track before every call.
- **Manager view** — coaching queue across the team.

## Who it's for

AEs and sales managers who want consistent execution without micromanagement.
